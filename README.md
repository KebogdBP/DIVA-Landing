# DIVA — рекламный концепт лендинга

Локальная статическая страница для презентации концепта iPhone-приложения. Страница не утверждает, что iOS-приложение уже выпущено. Обновлённый концепт включает «Мои файлы» — хранение результатов и быстрый доступ через нижнее меню.

Первый экран построен вокруг векторного начертания DIVA, повторяющего форму букв на предоставленном экране iPhone. Под буквенным знаком стоит крупный слоган «Искусство работы с файлами», а ниже одной строкой раскрыта аббревиатура: Documents, Images, Videos, Audios. Слоган и расшифровка выровнены по началу букв DIVA, без захода под шевроны. Внизу названы три задачи: загрузка, конвертация, сохранение. GSAP последовательно раскрывает знак и подписи; при отключённой анимации всё содержание остаётся видимым. Знак в шапке и на первом экране использует один SVG-файл.

Открыть локально из корня репозитория: `npm run serve`, затем перейти на `http://127.0.0.1:5173/`. Сервер должен продолжать работать, пока вы пользуетесь локальной страницей; если он остановился, запустите команду снова.

Шрифты — Exo 2 для основного текста и IBM Plex Mono для меток. Палитра и правила использования логотипа описаны в `brand/step-2-brand-landing-brief.md`. Изображения Unsplash и Pixabay, а также демонстрационный ролик Pexels сохранены локально; авторы и ссылки указаны в `assets/CREDITS.md`.

Новая сцена `#explore` стоит перед видеодемонстрацией. Карточки файлов расположены в сфере: прокрутка страницы поворачивает её, карточки также можно двигать мышью, а телефон — слегка вращать. При выборе карточка перелетает на экран DIVA. Видео проходит через выбор разрешения, прогресс и «Мои файлы»; PDF можно подписать или сжать, затем сохранить и открыть. Для DOCX, изображений и аудио есть короткие ветки конвертации или обрезки. Это интерактивный прототип интерфейса: файлы на сервер не загружаются, операции с ними имитируются.

Сцена использует Motion для связи со скроллом, Lenis для плавной прокрутки на десктопе, Three.js для координат сферы и GSAP для перелёта карточек и интерфейса. Исходник — `explore.js`, готовый локальный модуль — `explore.bundle.js`. После изменения исходника выполните `npm install` и `npm run build:explore` из каталога `landing`. Для простого просмотра сборка не нужна.

Ниже сохранён прежний видеосценарий: GSAP 3.15.1 перемещает видеокадр из стилизованной страницы просмотра в область «Добавить файл» на предоставленном скриншоте iPhone. Затем появляются стеклянные панели загрузки, выбор 480p и прогресс. Кадр переходит в «Мои файлы» и открывается. Кнопки позволяют повторить и приостановить последовательность. На странице проигрывается локальный стоковый ролик; интерфейс страницы просмотра — иллюстрация, не встроенный YouTube.

Three.js 0.180.0 также рисует сдержанный поток точек на фоне видеосцены. Библиотеки находятся локально в `assets/vendor/`, без зависимости от CDN. Если WebGL отключён, для потока точек используется Canvas с проекцией через камеру Three.js; сфера файлов работает без WebGL. При `prefers-reduced-motion` длинные переходы пропускаются. Демонстрация не скачивает видео с YouTube и не сохраняет файлы.

Актуальные бренд-ассеты и описание палитры лежат в `brand/`. Превью и промежуточные дизайн-экспорты не входят в репозиторий.
